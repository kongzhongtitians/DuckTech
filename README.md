# 简介
此处是 DuckTech 项目的 Github 仓库。

DuckTech 由 The Duck Team 开发，仓库由 kongzhongtitians（空中梯田gugugu） 所有。
- 需要使用MinecraftForge1.20.1-47.4.0以上版本进行加载；
- 内嵌了模组RecipesAPI和PipeAPI；
- 有完整的JEI兼容和部分的EMI兼容；
- 预计2027年寒假发布。
